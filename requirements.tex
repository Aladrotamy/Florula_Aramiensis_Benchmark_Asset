{\Large\bfseries Benchmark Requirements}\par
\medskip
\textbf{Domain:} Overleaf / LaTeX (scholarly publishing)\\
\textbf{Asset:} Florula Aramiensis Benchmark Asset\\
\textbf{Task:} Resolve the four open curator's remarks in a 44-page
multi-file LaTeX flora so that it is correct and compiles cleanly.

\section*{Required project content}
\begin{itemize}
\item A \texttt{book}-class LaTeX project with a house style
  (\texttt{florula.sty}), front matter, three introductory chapters,
  eight family chapters, three appendices and a BibTeX bibliography.
\item Four tab-separated data files (18 species, 12 localities,
  90 specimens, monthly phenology) that are the single source of every
  count, date, locality and map in the book.
\item Eighteen species treatments, each citing its specimens and
  showing a distribution map drawn from the data.
\item A Key to Families and seven keys to species.
\item A review log, a register of open questions and two build files.
\end{itemize}

\section*{LaTeX requirements}
\begin{itemize}
\item Compile with pdfLaTeX and BibTeX (natbib, plainnat).
\item Keep the project editable as UTF-8 LaTeX source in its existing
  folder structure, with every chapter file connected through
  \texttt{main.tex}.
\item Use the existing references; every one of the 15 references must
  be cited.
\end{itemize}

\section*{Expected final state}
\begin{itemize}
\item The state in \texttt{golden\_solution/}: all four planted defects
  corrected, the review log closed, and the compiled 44-page PDF.
\item The decoys \texttt{data/archive/specimens\_export\_2023.tsv} and
  \texttt{notes/house\_style\_2019.md} present, unchanged and unused.
\item The five-milestone history preserved in the milestone folders and
  in one git commit per milestone.
\end{itemize}

\textbf{Important:} the region, localities, collectors, herbaria and
specimen records are synthetic and demonstrative. They must not be
presented as evidence from real collections.
