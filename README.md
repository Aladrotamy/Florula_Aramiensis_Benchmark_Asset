# Florula Aramiensis Benchmark Asset

An OSWorld v2 base asset for the Overleaf / LaTeX domain.

*Florula Aramiensis, Volume I: Economic Trees* is a 44-page scholarly regional flora: a multi-file LaTeX book with its own house style, a synthetic but rule-bound data layer, identification keys, distribution maps, appendices and a bibliography of 15 published works. The starting state contains four planted defects of four different kinds; the golden solution is verified to score 1.0000.

## Quick start

Requirements: a TeX distribution with pdfLaTeX and BibTeX (tested with MiKTeX 26.5 and TeX Live 2023) and Python 3.8 or later (tested with 3.12.10). No Python packages beyond the standard library are needed.

From the asset root:

```
python verifier/verify.py golden_solution        # SCORE 1.0000
python verifier/verify.py project_source         # SCORE 0.6154
python verifier/run_oracle.py                    # ORACLE PASSED
python tools/make_specimens.py --out regen       # regenerates the data byte-for-byte
python tools/make_variant.py --name variant_C --seed 7 --per-species 6
```

In Overleaf: upload the contents of `golden_solution/` (or `project_source/`) as a new project, set the compiler to pdfLaTeX, and set `main.tex` as the main document.

## Reproducibility

- All text files are stored with LF line endings (`.gitattributes`); 0 files with CRLF in the repository.
- The data are regenerated byte-for-byte by a seeded script.
- The verifier normalises line endings, so it gives the same result on Windows, macOS and Linux.
- `MANIFEST.sha256` lists a checksum for every tracked file.

## Data note

The Arami Uplands, their localities, collectors, herbaria and all specimen records are fictional. The species, their descriptions, uses, synonyms and author citations follow the published literature cited in the book. The specimen data are demonstrative and must not be cited as records of real collections.
